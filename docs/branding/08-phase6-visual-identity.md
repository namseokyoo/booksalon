## 1. 색상 시스템 (✅ 확정)

### 색상 결정 과정 (Decision Journey)

#### Step 1: 현황 진단 (문제 인식)
기존 북살롱 디자인 시스템 분석 결과, 3가지 색상이 각각 불일치:

"다정한 현자" 퍼소나와 모두 맞지 않음을 3자(CEO, 오펜하이머, Gemini)가 합의.

| 방향 | 제안자 | 색상 |

#### Step 3: 회장님 레퍼런스 이미지

회장님이 북살롱 앱 목업 이미지를 공유. 딥 세이지 그린 + 앰버 + 베이지 조합.

#### Step 4: 회장님 피드백 — "둔해보인다"

> "상단 네비바 쪽 색은 좀 무거워보이는것 같아. 둔해보인다랄까?"

원인 분석:
- 목업의 세이지 그린이 올리브 계열 (Hue ~120)로 노란기가 많아 "둔탁함" 발생
- 파란쪽으로 Hue를 이동하면 "맑고 지적인" 느낌으로 전환 가능

```
노란 ←————— 녹색 스펙트럼 ————→ 파란
(카페/숲)     (목업 Hue 120)      (도서관/지성)
Hue 100       둔함 발생          Hue 150-170 맑음
```

#### Step 5: 3가지 Primary Green 후보 비교

| 후보 | Hue | 느낌 |

#### Step 6: 트렌드 검증

2025-2026 디자인 트렌드 조사:
- **Teal/Blue-Green이 2026 핵심 컬러** (WGSN "Transformative Teal")
- 짙은 Primary 여전히 유효 ("calmer, deeper, more focused")
- 독서앱 시장: 미니멀 + 클린 + 따뜻한 중립색 주류
- 한국 시장: 토스(OKLCH 도입), 당근(보조컬러 확장), 배민(기존색 정교화)
- C안(Hue 170°)이 트렌드 정중앙이나, 라이트모드 선호도와 다크모드 무거움 고려하여 B안(Hue 155°) 선택

회장님 선택: **시안 1 "다정한 도서관"** — "1번이 제일 좋아보이긴 하네"

### 색상 조화 구조

```
색상 휠:
        155° (Primary: 블루-세이지)
         ↑
    ╱‾‾‾‾‾‾‾╲
   ╱           ╲
  65° (CTA)    35° (Accent)
  앰버          테라코타
```

- Hue 155° ↔ Hue 65°: 90° 차이
- Hue 155° ↔ Hue 35°: 120° 차이
- Hue 155°의 보색(335°) 양쪽에 35°와 65°가 위치 → Split-Complementary

## 2. 타이포그래피 (✅ 확정)

### 이중 서체 전략 (Dual Typography)

**UI 서체 (산세리프)**: Pretendard Variable — 유지
**브랜드 서체 (세리프)**: 마루 부리 (Maru Buri) — 신규 도입

### 서체 결정 과정 (Decision Journey)

#### Step 1: 3자 의견 수렴

| 항목 | 오펜하이머 (Advisor) | Gemini |
|------|---------------------|--------|
| 세리프 도입 | 필요 (합의) | 필요 (합의) |
| 서체 1순위 | KoPub Batang Regular | RIDIBatang |
| 적용 범위 | 좁음: 히어로 타이틀 + 인용문만 | 넓음: 타이틀 + 인용문 + 질문 + 빈 상태 |

**핵심 합의**: 세리프 도입 필요, Pretendard는 UI 서체로 유지, 세리프 적용 범위는 제한적으로.

#### Step 2: 회장님 추가 후보 제안 — 서울한강장체

회장님이 서울한강장체를 추가 후보로 제안. 3개 서체(KoPub Batang, RIDIBatang, 서울한강장체) 심층 비교 조사 진행.

| 기준 | KoPub Batang | RIDIBatang | 서울한강장체 |
|------|-------------|------------|-------------|
| 제작 | 한국출판인회의 | 리디(주) | 서울시 + 윤디자인 |
| 철학 | 전자출판 산업 활성화 | 전자책 최적 가독성 | 한옥 곡선미 + 선비정신 |
| 성격 | 전통적, 격식 | 현대적, 미니멀 | 하이브리드 (고딕+명조 사이) |
| 굵기 | 3종 (L/M/B) | 1종 (Regular만) | 5종 (L/M/B/EB/BL) |
| 라이선스 | **웹폰트 승인 필요** | OFL (자유) | 공공누리 1유형 (자유) |

**KoPub Batang 리스크 발견**: 웹폰트 서버 탑재 시 별도 승인 필요, 서브셋 제작도 사전 승인 필요.
**RIDIBatang 한계**: Bold 미지원으로 디자인 위계 표현 불가.

#### Step 3: 가변폰트 필요성 검토 + 추가 후보 탐색

회장님 질문: "가변폰트 미지원이 아쉬울 수 있는 상황일까요?"

**분석 결론**: 북살롱에서는 아쉽지 않음.
- 세리프를 제목 + 인용문에만 쓰면 2개 굵기면 충분
- CJK 폰트는 가변폰트 파일이 거대해져 이점 상쇄
- 성능 차이 ~50-100KB (이미지 한 장 이하)

**추가 후보 발굴**:

| 서체 | 굵기 | Google Fonts | 라이선스 | "따뜻한 지성" |
|------|------|:-----------:|---------|:----------:|
| **마루 부리** | 5종 | X | OFL | ★★★★★ |
| **Noto Serif KR** | 7종 | O | OFL | ★★★★ |
| 서울한강장체 | 5종 | X | 공공누리 | ★★★★ |
| 이롭게 바탕체 | 1종 | X | OFL | ★★★★ |

#### Step 4: 마루 부리 선정

**마루 부리 (Maru Buri)** 선정 이유:
- 네이버 AG팀 제작, "화면에 따뜻함을 주는 부리체"라는 설계 철학
- 둥근 획 마감 = "다정한 현자"의 Caregiver(따뜻함), 명조 구조 = Sage(지성)
- 5종 굵기 (ExtraLight~Bold)로 디자인 위계 표현 충분
- OFL 라이선스 — 웹폰트, 서브셋 모두 자유
- 디지털 화면 전용 설계로 가독성 최적화

회장님: **"마루부리체로 적용하시죠"** → 확정.

### 마루 부리 (Maru Buri) 상세

| 항목 | 내용 |
|------|------|
| 제작 | 네이버 AG (마루 프로젝트) |
| 철학 | "화면에 따뜻함을 주는 부리체" |
| 라이선스 | SIL Open Font License 1.1 |
| 굵기 | ExtraLight(200) / Light(300) / Regular(400) / SemiBold(600) / Bold(700) |
| 가변폰트 | 미지원 (불필요 — 2개 굵기 사용 시 정적이 더 효율적) |
| Google Fonts | 미등록 (자체 호스팅 또는 CDN) |

### 적용 설계

```
[세리프 — 마루 부리]
├── 히어로 섹션 제목 (h1) — SemiBold(600) 또는 Bold(700)
├── 인용문 (blockquote) — Regular(400)
└── 빈 살롱 안내 문구 — Regular(400)

[산세리프 — Pretendard Variable]
├── 네비게이션, 버튼, 탭
├── 살롱 카드 제목/본문
├── 질문 목록
├── 모든 UI 요소
└── 본문 텍스트
```

### 세리프 적용 가이드라인

| 규칙 | 내용 |
|------|------|
| letter-spacing | 세리프에는 -0.01em ~ -0.02em 적용 (자간 좁히기) |
| line-height | 1.6 ~ 1.75 (여유로운 행간) |
| 다크모드 주의 | 가는 획 halation(번짐) 방지: font-weight 400 이상 사용 |
| 양피지+세리프 과잉 방지 | 적용 범위를 히어로/인용문으로 제한하여 "고풍 과부하" 회피 |
| 폴백(fallback) | font-family: 'MaruBuri', 'Noto Serif KR', serif |

### 아키타입 ↔ 서체 매핑

| 아키타입 | 대응 서체 | 근거 |
|---------|----------|------|
| 현자 (Sage) 60% | 마루 부리 — 명조 구조의 지적 깊이 | 세리프 = 지성, 전통, 신뢰 |
| 돌봄이 (Caregiver) 30% | 마루 부리 — 둥근 획 마감의 따뜻함 + Pretendard의 친근함 | 둥근 곡선 = 부드러움, 환대 |
| 탐험가 (Explorer) 10% | Pretendard Variable — UI의 현대적 활력 | 산세리프 = 현대, 탐색, 발견 |

## 3. 로고 방향 (🔄 보류 — 디자이너 브리프 준비 완료)

### 로고 검토 과정 요약

#### 3자 합의 사항
- **로고 유형**: 조합형 (심볼 + 워드마크), 심볼 단독 사용 가능하도록
- **색상**: 블루-세이지 주도 + 앰버 포인트
- **절대 금지**: 펼친 책, 돋보기, 전구, 그라데이션, 미용 연상 요소

#### 시도한 접근 (Round 1~3)

| Round | 접근 | 결과 |
|-------|------|------|
| 1 | 구두점 로고 (물음표, 쉼표) | 회장님: "로고 느낌이 전혀 없다" — 지나치게 미니멀 |
| 2 | 책+쪽지+물음표 (래스터 이미지) | 방향성 OK, 3자 크로스체크 7.1/10. 그러나 AI 생성은 일러스트에 가까움 |
| 3-1 | 책+쪽지+물음표 (SVG 직접 설계) | 기하학적 로고 접근, 쪽지 위치/책 심플화 반복 조정 |
| 3-2 | 물음표 제거 검토 | "물음표가 FAQ/도움말로 오독될 수 있다" — 물음표 없는 방향도 유효 |
| 3-3 | BS 레터마크 (타이포그래피) | 5변형 시도 (클래식/인터락/스택/네스팅/대비) |

#### 도출된 핵심 인사이트

1. **AI 이미지 생성은 로고에 부적합** — 일러스트는 잘 만들지만, 로고에 필요한 기하학적 정밀성과 극도의 단순함은 전문 디자이너 영역
2. **물음표 사용은 선택 사항** — 쪽지/책갈피만으로도 "발견의 느낌" 전달 가능
3. **레터마크(BS)도 유력한 방향** — 이솝/롱블랙 톤에 가장 가까운 접근
4. **파비콘 전용 변형은 필수** — 어떤 방향이든 32px 이하 별도 설계 필요

#### 확정 대기: 전문 디자이너 브리프

추후 전문 디자이너에게 의뢰 시 활용할 브리프 핵심:
- 컨셉 A: "책 속 쪽지" — 닫힌 책 + 삐져나온 앰버 쪽지 (물음표 선택)
- 컨셉 B: "BS 레터마크" — 세리프 모노그램, 장서표(ex-libris) 스타일
- 색상: #4A6B5D(세이지) + #C4882B(앰버) 확정 팔레트
- 톤: 이솝 x 독립서점 x 롱블랙
- 필수 산출물: 조합형, 심볼 단독, 파비콘 전용, 가로 배치형, 다크모드, 모노크롬
- 시안 파일: `/Volumes/external/project/booksalon/logo-drafts/` 참조

## 4. 이미지 스타일 (✅ 확정)

### 3자 합의: 미니멀 라인 일러스트 + 수채화 워시 하이브리드

| 구분 | 스타일 | 상세 |
|------|--------|------|
| **UI 내부** (빈 상태, 온보딩) | SVG 라인아트 | 세이지 단색, stroke 1.5px, fill 없음 |
| **마케팅/블로그** (OG이미지, 배너) | 라인 + 수채화 워시 | 세이지 + 크림 톤 수채화 배경 위 라인아트 오버레이 |

### 색상 규칙

| 규칙 | 내용 |
|------|------|
| 색상 수 | 이미지당 최대 2색 + 배경 |
| 앰버 사용 | **금지** — CTA 전용 색상이므로 이미지에 사용하지 않음 |
| 다크모드 | SVG는 CSS 변수(`currentColor`)로 자동 전환 |
| 금지사항 | 얼굴 표현, 사진풍 렌더링, 복잡한 장면 |

### 나노바나나(Gemini) 프롬프트 템플릿

| 용도 | 프롬프트 |
|------|---------|
| 빈 상태 | "Minimal single-line illustration of [subject], sage green (#4A6B5D) on off-white, no fill, 1.5px stroke" |
| 블로그 히어로 | "Watercolor wash background in muted sage and cream tones, with thin line illustration of [subject] overlaid" |
| OG 이미지 | "Clean minimal composition, left-aligned thin line art of [subject], right side text area, sage monochrome" |
| 아이콘 일러스트 | "Simple geometric line icon of [subject], rounded corners, 2px stroke, sage green on transparent" |

### 아키타입 매핑

| 아키타입 | 이미지 표현 |
|---------|------------|
| 현자 (Sage) 60% | 절제된 라인, 여백, 단색 |
| 돌봄이 (Caregiver) 30% | 수채화 워시의 부드러움, 크림 톤 |
| 탐험가 (Explorer) 10% | 손그림 느낌의 자유로운 라인 |

## 5. 아이콘 스타일 (✅ 확정)

### 아이콘 라이브러리: Lucide Icons (기존 유지)

#### 3자 검토 요약

| 항목 | 오펜하이머 (Advisor) | Gemini |
|------|---------------------|--------|
| 추천 라이브러리 | **Lucide Icons** | Phosphor Icons (Light) |
| 근거 | 기존 코드 호환, 마이그레이션 비용 0 | 차별화, Duotone 옵션 |

**CEO 판단**: Lucide 유지. 기존 shadcn/ui 기반 코드와 호환성 우선. 차별화는 커스텀 아이콘 4종으로 해결.

### 아이콘 스타일 규격

| 속성 | 값 |
|------|-----|
| 라이브러리 | Lucide Icons |
| Stroke width | 2px |
| Stroke linecap | round |
| Stroke linejoin | round |
| 기본 크기 | 24×24px (w-6 h-6) |
| 색상 | 시맨틱 토큰 (`currentColor` 기반) |

### 시맨틱 아이콘 색상 토큰

| 상태 | 토큰 | 용도 |
|------|------|------|
| 기본 | --icon-default | 네비게이션, 일반 UI |
| 비활성 | --icon-muted | 비활성 탭, 보조 |
| 강조 | --icon-primary | 선택된 탭, 활성 상태 |
| CTA | --icon-cta | CTA 내부 아이콘 |

### 커스텀 아이콘 4종 (제작 필요)

| 아이콘 | 용도 | 설명 |
|--------|------|------|
| 살롱 (Salon) | 살롱 탭/카드 | 책 + 대화 모티프 |
| 토론 프롬프트 (Discussion) | 질문 카드 | 말풍선 + 물음표 |
| 공감 (Empathy) | 리액션 | 따뜻한 하트/손 변형 |
| 읽기 상태 (Reading Status) | 진행률 | 펼친 책 + 프로그레스 |

> 커스텀 아이콘은 Lucide 스타일(stroke 2px, round, 24×24 grid)에 맞춰 SVG로 제작.
