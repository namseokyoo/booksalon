## 1. 창립자가 정의한 타겟 사용자

### 핵심 페르소나: "여운을 나누고 싶은 독자"

> "책을 읽고 그 책을 좀더 씹고 뜯고 맛보기를 원하는사람. 하지만 혼자의 생각보다 다른사람의 생각이 궁금하고, 책이 주는 여운을 오래 가져가는 사람입니다."

### 현재 행동 (대안)

| 현재 하는 것 | 한계 |
|-------------|------|
| 독서모임을 찾아본다 | 시간/장소 제약, 원하는 책이 아닐 수 있음 |
| 혼자 메모한다 | 대화가 없어 깊이에 한계 |
| SNS에서 같은 책 읽은 사람을 찾는다 | 찾기 어렵고, 찾아도 깊은 대화가 안 됨 |
| 아무것도 안 한다 | 여운이 사라짐 |

### 핵심 페인포인트

> "내가 궁금한것에 대해 이야기를 나눌 사람을 찾기는 어렵습니다."

### 사용 빈도 (창립자 기준)

- 월 2권 독서
- 거의 매번(1~2권) 대화 욕구 발생
- → 2주에 1번 새로운 살롱을 찾는 패턴 (커뮤니티 적정 방문 빈도)

### Founder-Market Fit

> "나 역시도 북살롱의 타겟 사용자입니다. 독서모임, 독서 경험을 하면서 느낀 생각과 감정, 경험을 바탕으로 북살롱은 생각했고, 만들고 싶었습니다."

## 2. 브랜드 핵심 이미지

> "도서관에서 빌린책에 있던 궁금함을 적은쪽지를 발견한 느낌처럼 북살롱이 다가갔으면 합니다."

| 가치 | 쪽지 경험에서의 모습 |
|------|-------------------|
| 연결 | 모르는 사람이지만 같은 책으로 연결됨 |
| 환대 | 답을 적어주고 싶은 마음 |
| 깊이 | 단순 감상이 아닌 궁금함 |
| 즐거움 | 발견의 기쁨 |
| 영속성 | 시간을 넘어 남겨진 질문 |

## 3. 페르소나 3인 (확정)

### 회장님이 정의한 역할

| 페르소나 | 유형 | 회장님 정의 | 성장 단계 |
|---------|------|-----------|----------|
| **이지훈** (32, 기획자) | 지적 갈증형 | "가장 호기심을 느낄 사람" — 첫 번째로 올 사용자 | 1단계: 질문으로 살롱을 연다 |
| **윤서연** (28, 마케터) | 여운 감성형 | "가장 어울리는 사람" — 북살롱 문화의 체현자 | 2단계: 환대로 문화를 만든다 |
| **박민우** (45, 번역가) | 시공간 횡단형 | "가장 있었으면 하는 사람" — 비전의 완성자 | 3단계: 시간을 넘는 대화를 시작한다 |

### 상세 프로필

**이지훈 (지적 갈증형) — 1차 타겟**
- 32세, IT 서비스 기획자
- 인문학, 사회과학, 비즈니스 도서 위주. 노션에 인사이트 정리
- 핵심 불만: 주위에 딥한 지적 대화 나눌 사람 부재
- 사용 시나리오: 완독 후 저자의 특정 주장에 반대 의견이 있을 때, 논의의 판을 까는 발제자
- 북살롱 역할: **질문 생성기** — 살롱에 첫 질문을 던지는 사람

**윤서연 (여운 감성형) — 문화 형성자**
- 28세, 콘텐츠 마케터
- 소설, 에세이 위주. 출퇴근길 독서. 인스타 스토리에 문장 공유
- 핵심 불만: 각잡힌 독서모임은 부담, 하지만 공감 나누고 싶음
- 사용 시나리오: 소설의 충격적 결말을 읽은 밤, 감성적 질문을 남기거나 공감하는 답장
- 북살롱 역할: **커뮤니티 온도 유지** — 환대의 문화를 만드는 사람

**박민우 (시공간 횡단형) — 비전 완성자**
- 45세, 프리랜서 번역가
- 고전 문학, 역사서, 철학서. 절판된 책이나 명저 재독
- 핵심 불만: 마이너하거나 오래된 책에 대해 이야기 나눌 공간 전무
- 사용 시나리오: 10년 전 출간 책을 읽다 3년 전 누군가 남긴 똑같은 질문을 발견, 정성스러운 답장
- 북살롱 역할: **롱테일 콘텐츠 활성화** — 시공간 초월 대화를 완성하는 사람

### 성장 경로

```
1단계: 이지훈이 온다 (질문으로 살롱을 연다)
     ↓
2단계: 윤서연이 온다 (환대로 문화를 만든다)
     ↓
3단계: 박민우가 온다 (시간을 넘는 대화가 시작된다)
```

## 4. 타겟 세그먼트 계층

| Tier | 세그먼트 | 설명 | 예상 비중 |
|------|---------|------|----------|
| Tier 1 | 탐구적 독서가 (이지훈/윤서연/박민우) | 핵심 타겟. 콘텐츠 생산자 | 20-30% |
| Tier 2 | 관찰형 독서가 | 다른 사람의 대화를 읽고 공감. "나도 궁금해요" | 50-60% |
| Tier 3 | 독서모임 오거나이저 | 발제 질문 활용 (B2B2C 가능성) | 5-10% |
| Tier 4 | 작가/출판 관계자 | 독자의 진짜 질문을 알고 싶은 사람 (장기) | 미래 |

### 경계: 배제할 세그먼트
- 별점/리뷰 작성자 — Phase 1에서 명확히 배제
- 평가성 게시물 유입 시 구조적 장치(질문 형식 유도) 필요

## 5. 사용 맥락 (Use Context)

| 맥락 | 상황 | 시간대 |
|------|------|--------|
| **독서 직후의 밤** (핵심) | 마지막 장을 덮은 직후, 감상과 의문이 최고조 | 밤 10시~새벽 1시 |
| **독서 중 막히는 구간** | 이해 안 되거나 맥락이 궁금할 때 | 독서 중 |
| **일상 속 Flashback** | 뉴스나 대화에서 예전 읽은 책이 떠올랐을 때 | 수시 |
| **응답 알림의 설렘** | 내 질문에 답장이 달렸을 때 | 수시 |

## 6. "도서관 쪽지" 이미지 활용 아이디어 (Phase 4/6에서 구체화)

### UX 카피 방향
- 글쓰기 → "쪽지 남기기" 또는 "질문 꽂아두기"
- 댓글 → "답장하기" 또는 "생각 덧붙이기"
- 알림 → "누군가 당신이 남긴 쪽지를 발견하고 답장을 남겼습니다"

### UI 방향
- 미색(Ivory) 배경, 텍스트 집중 환경
- "누군가 책갈피 사이에 남겨둔 질문들" 큐레이션 (우연한 발견 UI)
- 프로필/팔로워 수 같은 과시적 요소 배제, 책 중심의 느슨한 연대
