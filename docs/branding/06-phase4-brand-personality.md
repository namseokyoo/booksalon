## 1. 창립자가 묘사한 브랜드 인격

> "따뜻한 머플러를 하고 커피를 마시며 옅은 미소를 지으며 책을 읽고있는 순정만화톤의 남자. 그리고 그 사람이 50년후에 나이를 먹고도 미소지으며 책을 읽고 있는 모습."

> "혼자 책을 읽는 모습이 외롭거나 내향적으로 보일수도 있지만 막상 이야기를 시작하고 공감대가 형성되면 적극적으로 질문하고, 이야기를 나누는 모습."

> "본인은 매너있는 말투와 고급스러운 어휘를 사용하면서도 다른사람의 다양한 톤의 말은 잘 들어주고 열린 생각으로 받아주는 성격."

### 성격의 반전 구조

| 겉보기 | 실제 |
|--------|------|
| 혼자 조용히 읽는 사람 | 공감대가 생기면 적극적으로 질문하고 대화 |
| 고급스러운 어휘, 매너 있는 말투 | 다른 사람의 다양한 톤은 열린 마음으로 수용 |
| 외롭거나 차가워 보일 수 있음 | 따뜻하고 환대하는 성격 |

이 반전이 사용자 여정 그 자체:
```
처음 방문 → "조용하고 고급스러운 공간이네" (겉보기)
질문을 던짐 → "어, 누가 진심으로 답해주네" (반전)
대화가 깊어짐 → "이 사람들 정말 따뜻하다" (본질)
```

## 2. 브랜드 아키타입

### 3자 합의: "다정한 현자"

| 아키타입 | 비중 | 역할 |
|---------|------|------|
| **현자 (The Sage)** | 60% | 질문, 지혜, 깊이, 진실 추구 |
| **돌봄이 (The Caregiver)** | 30% | 환대, 포용, 따뜻함, 수용 |
| **탐험가 (The Explorer)** | 10% | 우연한 발견, 쪽지의 세렌디피티 |

### 균형의 원칙
- Sage가 지나치면 → 차갑고 권위적 → Caregiver가 방지
- Caregiver가 지나치면 → 감상적이고 얕아짐 → Sage가 방지

## 3. 톤앤매너 (회장님 확정)

### 스펙트럼 (5점 척도)

```
격식 ■■■□□ 캐주얼    (캐주얼 방향 2)
활기 □□□■■ 차분      (차분 방향 2)
전문 □■■■■ 친근      (친근 방향 4)
간결 □□■□□ 서술적    (중간)
```

### 한 문장 정의
> **"매너 있지만 편안한, 조용하지만 따뜻한"**

### 어휘 수준
- "잘 읽히는 에세이" 수준
- "학술 논문" 수준이 아님
- 예: "사유하다"보다 "생각을 나누다"

### 톤 가드레일

```
[금지]          [주의]          [적정]          [주의]          [금지]
권위적/냉담 --- 사무적/건조 --- 따뜻한 정중함 --- 감상적/수다 --- 과잉친근/반말
                              ↑ 여기가 북살롱
```

## 4. 감정 키워드

사용자가 북살롱을 경험할 때 느꼈으면 하는 감정:

| 키워드 | 의미 |
|--------|------|
| **환대받음 (Welcomed)** | 평가가 아닌 반김의 공간 |
| **안온함 (Cozy)** | 비 오는 날 따뜻한 조명 아래의 차분함 |
| **지적 충만함 (Fulfilled)** | 깊은 사유를 나눈 후의 만족 |
| **여운 (Resonant)** | 쪽지를 발견했을 때의 몽글몽글한 감동 |
| **느슨함 (Relaxed)** | 각자의 속도를 존중받는 편안함 |
| **영속성 (Timeless)** | 10년 후에도 이 자리에 있을 든든함 |

## 5. 브랜드 보이스 DO & DON'T

### DO (이렇게 한다)

| 규칙 | 예시 |
|------|------|
| 여지를 남기는 표현 | "~해보는 건 어떨까요", "~일지도 모릅니다" |
| 서술형 종결어미 | "~합니다", "~이에요", "~네요" |
| 질문을 질문으로 대함 | "어떤 부분이 인상적이었나요?" |
| 구체적 이미지 표현 | "긴 대화의 시작", "생각을 남기다" |
| 침묵도 허용 | 빈 상태를 "문제"로 프레이밍하지 않음 |
| 존대 유지, 딱딱하지 않게 | "~하셨군요" (O) / "~하였습니다" (X) |

### DON'T (이렇게 하지 않는다)

| 규칙 | 예시 |
|------|------|
| 느낌표 연속 금지 | "지금 바로!!" — 금지 |
| 이모지 본문 사용 금지 | UI 아이콘은 허용, 텍스트 내 이모지 금지 |
| 경쟁/비교 프레이밍 금지 | "1등 독서 커뮤니티" — 금지 |
| FOMO 표현 금지 | "지금 안 하면 놓칩니다" — 금지 |
| 유행어/밈 금지 | "ㄹㅇ", "갓생", "찐" — 금지 |
| 명령형 금지 | "작성하세요" → "작성해보실 수 있어요" |
| 과잉 칭찬 금지 | "대단해요!", "멋진 질문이에요!" — 금지 |

## 6. UX 카피 예시 (3자 종합)

### 온보딩
> "반갑습니다. 여기선 책에 대해 질문을 남기고, 누군가의 생각을 만날 수 있어요. 천천히 둘러보세요."

### 질문 작성 유도
> "이 책을 읽으며 떠오른 생각이 있나요? 짧은 질문 하나가 긴 대화의 시작이 되기도 합니다."

### 답변 알림
> "당신이 남긴 질문에 누군가 생각을 남겼어요."

### 빈 살롱
> "아직 이 책에 대한 이야기는 시작되지 않았네요. 첫 번째 질문을 남겨보는 건 어떨까요."

### 에러
> "잠시 책갈피를 잃어버린 것 같아요. 금방 다시 제자리를 찾아놓을 테니, 조금만 기다려주세요."

### 재방문
> "다시 오셨군요. 그동안 어떤 문장들을 만나고 오셨는지 궁금했어요."

### 검색 결과 없음
> "아직 이 책에 대한 이야기는 도착하지 않았네요. 아마 당신이 첫 번째 발견자가 될 수 있을 거예요."

### 공감 액션
> 버튼: "이 생각에 머물기"
> 토스트: "조용히 갈피를 끼워둘게요."
