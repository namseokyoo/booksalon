# 북살롱 브랜딩 논의 #1: 킥오프

> 날짜: 2026-02-26
> 참석: 회장님(NAMSEOK), CEO Agent(노이만)

## 1. 브랜딩이란?

브랜딩은 단순히 로고나 색상을 정하는 것이 아니라, **"사람들이 우리 서비스를 떠올릴 때 느끼는 모든 것"**을 설계하는 작업.

### 브랜딩의 3개 층위

| 층위 | 내용 | 예시 |
|------|------|------|
| **1. 본질 (Why)** | 왜 존재하는가, 무엇을 믿는가 | "책은 혼자 읽지만, 이해는 함께 깊어진다" |
| **2. 전략 (How)** | 누구에게, 어떤 포지션으로, 어떤 성격으로 | 타겟, 경쟁 분석, 브랜드 퍼소낼리티 |
| **3. 표현 (What)** | 이름, 로고, 색상, 폰트, 톤앤매너, UX | 시각적/언어적 아이덴티티 |

핵심: **1번(본질)부터 시작해야** 일관되고 강한 브랜드가 만들어진다.

## 2. 권장 브랜딩 프로세스 (7단계)

### Phase 1: 브랜드 본질 정의
- **미션**: 이 서비스가 세상에 왜 존재하는가?
- **비전**: 궁극적으로 어떤 세상을 만들고 싶은가?
- **핵심 가치**: 어떤 원칙을 절대 타협하지 않는가?

### Phase 2: 타겟 오디언스 정의
- **핵심 페르소나**: 누가 이 서비스의 1번 사용자인가?
- **니즈 & 페인포인트**: 그들이 진짜 원하는 것은?
- **사용 맥락**: 어떤 상황에서 우리 서비스를 찾는가?

### Phase 3: 경쟁 분석 & 포지셔닝
- **경쟁 맵핑**: 유사 서비스들은 어떻게 자리잡고 있는가?
- **차별화 포인트**: 우리만의 고유한 가치는?
- **포지셔닝 스테이트먼트**: 한 문장으로 정의

### Phase 4: 브랜드 퍼소낼리티
- **성격**: 이 브랜드가 사람이라면 어떤 성격인가?
- **톤앤매너**: 어떻게 말하는가? (격식/캐주얼, 따뜻함/전문적)
- **감정 키워드**: 사용자가 느꼈으면 하는 감정

### Phase 5: 네이밍 & 슬로건
- **이름 검증**: "북살롱"이라는 이름의 적합성 검토
- **태그라인/슬로건**: 기억에 남는 한 줄
- **스토리**: 이름에 담긴 이야기

### Phase 6: 비주얼 아이덴티티
- **로고**: 심볼 + 워드마크
- **컬러 시스템**: 브랜드 컬러 (OKLCH 기반 토큰 구축 완료)
- **타이포그래피**: Pretendard Variable 적용 완료
- **이미지 스타일**: 사진/일러스트 방향

### Phase 7: 브랜드 가이드라인 & 적용
- **브랜드 북**: 모든 규칙을 한 문서로
- **적용**: 웹사이트, SNS, 마케팅 자료에 일관되게

## 3. 현재 북살롱 브랜딩 상태 진단

| 항목 | 상태 | 비고 |
|------|------|------|
| 미션/비전 | △ 존재하지만 정제 필요 | PRD에 기본 정의 있음 |
| 타겟 페르소나 | △ 암묵적으로 존재 | 명시적 정의 필요 |
| 포지셔닝 | ✗ 미정의 | 경쟁 분석 필요 |
| 퍼소낼리티 | ✗ 미정의 | |
| 네이밍 | ✓ "북살롱" | 검증 필요 |
| 비주얼 시스템 | ◎ 상당히 진행됨 | 디자인 토큰, 다크모드 완성 |
| 브랜드 가이드 | ✗ 미정의 | |
