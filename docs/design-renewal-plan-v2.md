# 북살롱 디자인 리뉴얼 계획 v2

> 작성일: 2026-02-26
> 작성: CEO Agent (Claude + Gemini 크로스 검토)
> 상태: Phase 1 착수 대기 (브랜딩 방향 확정 후 진행)

## 배경

회장님이 "디자인적으로 뭔가 부족한 느낌, 페이지에 킥이 부족하다"고 지적.
Claude(코드 분석) + Gemini CLI(실제 사이트 브라우저 확인) 크로스 검토를 통해 문제점을 도출하고 리뉴얼 방향을 수립함.

## 핵심 진단 (Claude + Gemini 크로스 검토 확정)

| # | 문제 | 심각도 | 출처 |
|---|------|--------|------|
| 1 | **사이트 목적 혼란** — 검색바가 먼저 보여 "책 검색 사이트"로 오인 | 높음 | Gemini |
| 2 | **Hero 섹션 부재** — 브랜드 정체성 전달 실패 | 높음 | Claude + Gemini |
| 3 | **GNB 없음** — 모든 기능이 드롭다운에 숨김 | 높음 | Claude |
| 4 | **카드 여백 부족** — 16px 미만, 정보 밀집으로 가독성 저하 | 중 | Gemini |
| 5 | **색상이 차갑다** — 독서 커뮤니티 감성 부족, 무채색 위주 | 중 | Gemini |
| 6 | **타이포그래피 위계 불명확** — 제목/본문 구분 약함 | 중 | Claude + Gemini |
| 7 | **애니메이션 전무** — 정적 페이지, "킥" 부재 | 중 | Claude |
| 8 | **하드코딩 색상** — OKLCH 토큰 정의되었으나 미사용 | 낮음 | Claude |
| 9 | **일러스트 없음** — 빈 상태/에러가 텍스트만 | 낮음 | Claude + Gemini |

## Phase 1: 즉시 체감 (구조 + Quick Win)

> 목표: 3초 안에 "여기는 독서 커뮤니티다"라는 인상 확립

| # | 작업 | 상세 | 난이도 | 효과 |
|---|------|------|--------|------|
| 1-1 | **Hero 섹션 신설** | "책과 사람이 만나는 살롱" 슬로건 + 추천 살롱 하이라이트 + CTA 버튼. 기존 검색바는 Hero 하단으로 이동 | 중 | 최대 |
| 1-2 | **사이트 목적 명확화** | Hero에 "독서 커뮤니티" 정체성 메시지 배치. 검색바 플레이스홀더를 "읽고 싶은 책이 있나요?"로 변경 | 낮음 | 높음 |
| 1-3 | **GNB 네비게이션** | 데스크탑: 상단 고정 (홈 / 살롱탐색 / 내활동). 모바일: 하단 고정 탭바 (홈 / 탐색 / 내살롱 / 프로필) | 중 | 높음 |
| 1-4 | **카드 여백 개선** | 카드 내부 padding 16→24px, 카드 간 gap 16→24px, 텍스트 블록 간 margin 추가 | 낮음 | 높음 |
| 1-5 | **정보 밀도 완화** | 살롱 카드: 핵심 3개(표지+제목+참여수)만 노출, 태그/평점 등은 호버 또는 상세에서. 인기 게시물: 통계 아이콘 간격 8px 확보 | 낮음 | 높음 |
| 1-6 | **타이포그래피 위계** | h1: 36px/bold, h2: 28px/bold, h3: 20px/semibold, body: 16px/normal, line-height 전체 1.6 이상 | 낮음 | 중 |
| 1-7 | **색상 토큰 통일** | 컴포넌트 하드코딩 색상을 시맨틱 토큰으로 전환 | 낮음 | 중 |

## Phase 2: 감성 레이어

> 목표: "따뜻한 서재 같은" 감성 주입

| # | 작업 | 상세 | 난이도 | 효과 |
|---|------|------|--------|------|
| 2-1 | **따뜻한 서브 팔레트** | 틸(hue 200) Primary 유지 + 워밍 서브컬러 추가 (앰버 hue 70, 테라코타 hue 30) | 중 | 높음 |
| 2-2 | **마이크로 인터랙션** | 카드 호버 scale-[1.02]+shadow-lg, 페이지 전환 fade-in 300ms, 좋아요 bounce, 카드 fade-up | 중 | 높음 |
| 2-3 | **로딩 스켈레톤** | spinner → 카드 형태 skeleton UI | 낮음 | 중 |
| 2-4 | **커스텀 일러스트** | 빈 상태 3종 + 에러 1종. 미니멀 라인아트, 책+사람 모티프 (나노바나나 생성) | 중 | 중 |
| 2-5 | **로고 리뉴얼** | 책+대화 모티프 커스텀 로고 + 파비콘 | 중 | 중 |

## 실행 전략

Phase 1 내에서 Quick Win (1-4, 1-5, 1-6, 1-7) 먼저 처리 후 구조 변경 (1-1, 1-2, 1-3) 진행.

```
Phase 1 (1~2주) → Phase 2 (2~3주) → Phase 3 (3~4주)
```

## 선행 조건

- **브랜딩 방향 확정 필요**: 로고, 색상, 톤앤매너 등 브랜드 아이덴티티가 확정되어야 Phase 1의 Hero 섹션과 Phase 2의 색상/로고 작업이 일관성 있게 진행됨.
