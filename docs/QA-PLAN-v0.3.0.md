## 1. 검증 개요

### 1.1 목적

북살롱 v0.3.0에서 추가된 4가지 핵심 기능(태그 시스템, 검색 개선, 이미지 업로드, 평점 시스템)이 PRD 요구사항을 충족하고, 다양한 유저 시나리오에서 정상 동작하는지 검증합니다.

### 1.2 범위

| 기능 | 우선순위 | 검증 범위 |
|------|----------|----------|
| **태그 시스템** | P0 | 살롱/게시물 태그 추가, 자동완성, 태그 기반 검색 |
| **검색 개선** | P0 | searchText 필드, 자동완성, 검색 히스토리, 하이라이트 |
| **이미지 업로드** | P0 | 게시물 이미지 첨부, 미리보기, 라이트박스, 최적화 |
| **평점 시스템** | P0 | 별점 입력/수정, 평균 평점, 평점 분포 |

### 1.3 검증 기간

- **예상 기간**: 2-3일 (Week 3)
- **검증 환경 준비**: 0.5일
- **시나리오 테스트**: 1.5일
- **버그 리포트 및 재검증**: 1일

### 1.4 검증 환경

| 항목 | 사양 |
|------|------|
| **브라우저** | Chrome 최신, Firefox 최신, Safari 최신 |
| **디바이스** | 데스크탑 (1920x1080), 태블릿 (768px), 모바일 (375px) |
| **네트워크** | 일반 연결 + 저속 연결 시뮬레이션 (3G) |
| **테스트 환경** | 로컬 개발 서버 (localhost:3000), Firebase Emulator |

### 3.1 태그 시스템 시나리오

#### SC-TAG-01: 살롱 생성 시 태그 추가 (P0)

| 항목 | 내용 |
|------|------|
| **시나리오 ID** | SC-TAG-01 |
| **제목** | 살롱 생성 시 태그 추가 |
| **관련 페르소나** | C (살롱 운영자) |
| **우선순위** | P0 |
| **사전 조건** | 로그인 상태, 새 살롱 생성 모달 오픈 |

**Given-When-Then:**
```
Given: 사용자가 새 살롱 생성 모달을 열었다
When: 책을 검색하여 선택하고, 태그 입력란에 "독서토론"을 입력한다
Then:
  - 입력 중 자동완성 드롭다운에 관련 태그가 표시된다
  - Enter를 누르면 태그가 칩 형태로 추가된다
  - 최대 5개까지 태그 추가 가능하다
  - 6번째 태그 추가 시 경고 메시지가 표시된다
```

**기대 결과:**
- 태그 자동완성 응답 시간 < 200ms
- 태그 칩 UI가 정상 표시됨
- 최대 개수 제한 동작
