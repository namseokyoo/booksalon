## 1. 개요

### 1.1 프로젝트 정의

**북살롱(Book Salon)**은 특정 도서에 대해 깊이 있는 대화를 나눌 수 있는 독서 커뮤니티 플랫폼입니다. ISBN 기반으로 특정 도서에 집중된 토론 공간(살롱)을 제공하며, 독자들이 독서 경험을 공유하고 다양한 관점을 교환할 수 있는 서비스입니다.

### 1.2 배경 및 문제 정의

#### 배경
- 국내 독서 커뮤니티는 블로그나 SNS 위주로 분산되어 있음
- 특정 책에 대한 집중적인 토론 공간 부재
- Goodreads와 같은 글로벌 서비스는 한국 독서 문화에 최적화되지 않음

#### 해결하고자 하는 문제
1. **분산된 독서 토론**: 같은 책을 읽은 독자들이 한 곳에서 토론할 수 있는 공간 부재
2. **도서 중심 커뮤니티 부재**: 도서를 중심으로 형성되는 커뮤니티 플랫폼 필요
3. **실시간 소통 어려움**: 기존 플랫폼의 비동기적 소통 방식의 한계

### 1.3 비전

> "책을 중심으로 독자들이 연결되는 지식 공유 커뮤니티"

|------|----------|----------|

## 8. 리스크 및 가정

### 8.1 리스크

| 리스크 | 영향도 | 발생 가능성 | 대응 방안 |
|--------|--------|------------|----------|
| **Supabase 무료 티어 초과** | 중간 | 낮음 | 사용량 모니터링, 유료 플랜 전환 대비 |
| **카카오 API 제한** | 중간 | 낮음 | 요청 제한, 캐싱 적용 |
| **사용자 증가 시 성능** | 높음 | 중간 | 페이지네이션, 인덱싱 최적화 |
| **소셜 로그인 정책 변경** | 중간 | 낮음 | 다중 로그인 옵션 유지 |
| **이미지 저장 용량** | 중간 | 중간 | 이미지 압축, 용량 제한 |
| **Cold Start 문제** | 높음 | 높음 | 시드 콘텐츠 + 베타 테스터 모집 (8.4 참조) |

### 8.2 가정

| 가정 | 검증 방법 |
|------|----------|
| 사용자는 책에 대한 토론에 관심이 있다 | 사용자 설문, 활성도 측정 |
| Supabase 무료 티어로 초기 운영 가능 | 사용량 모니터링 |
| 카카오 API는 안정적으로 제공된다 | API 모니터링, 대안 API 준비 |
| 사용자는 모바일 웹으로 충분히 만족한다 | 사용자 피드백, 이탈률 분석 |
